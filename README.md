# 11. Lost & Found Portal for College

### 🚀 Real-World Use
Students often lose ID cards, bottles, or calculators. This system allows a campus admin or student to log found items and search for them instantly.

### 🛠 Core Features
- **Add Item:** Appends item details (ID, Name, Category, Date) to a permanent file.
- **Search:** String-matching algorithm to filter items by category.
- **Persistence:** Uses C++ `fstream` so data is not lost when the program closes.

### 💻 How to Run (Lightweight Method)
Since this is a terminal-based C++ project:
1. Copy the code from `main.cpp`.
2. Paste it into [OnlineGDB](https://www.onlinegdb.com/online_c++_compiler).
3. Click **Run**.
