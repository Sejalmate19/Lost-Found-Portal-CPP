🔍 Lost & Found Portal

A Lightweight C++ Management System for College Campuses

Project Overview

This terminal-based application helps students and administrators track lost items like ID cards, calculators, and water bottles. It focuses on efficiency and data persistence without the need for a complex database engine.

C++ File Handling CLI Data Structures

Key Technical Features

  • File Persistence: Uses fstream to save data to database.txt, ensuring records remain after the program exits.
  • Optimized Search: Implements string-matching logic to filter items by specific categories.
  • Formatted Output: Utilizes <iomanip> for a clean, table-like display in the console.
  • Robust Data Structure: Uses a struct to group item attributes (ID, Name, Category, Date, Status).

How It Works (Logic)

The system stores data using a pipe-delimited format (|) which allows for easy parsing while keeping the file size extremely small and readable.

// Example format in database.txt:
101|College ID|ID Card|25/04/2026|0
102|Milton Bottle|Bottle|26/04/2026|0
